# 🎙 Text_To_Speech_TranTong

Tool đọc văn bản thành giọng nói **tiếng Việt**, chạy **ngay trên máy của bạn** (không cần internet sau khi cài, không gửi dữ liệu đi đâu).

- **Chế độ Thật** — nhái giọng, giống người thật hơn.
- **Chế độ Nhanh** — tạo nhanh, âm thanh 48 kHz trong trẻo.
- Giọng có sẵn 3 miền Bắc – Trung – Nam, tự nhái giọng từ một đoạn ghi âm, hoặc tự thiết kế giọng mới.
- Đọc số tiền, ngày tháng thành chữ; xuất file **WAV** hoặc **MP3**.

## Tải và cài

1. Vào mục [**Releases**](../../releases/latest), tải file **`Cai_Text_To_Speech_TranTong.exe`**.
2. Bấm chạy, chọn nơi cài, bấm **Cài đặt**. Lần đầu tải về vài GB (Python + giọng), nên cần mạng khỏe.
3. Cài xong, mở bằng biểu tượng **Text_To_Speech_TranTong** ngoài màn hình.
4. Lần đầu mở, nhập **Mã kích hoạt** (xin của người cấp phép).

Xem [HƯỚNG DẪN chi tiết](../../releases/latest) kèm trong bản tải về.

> Máy cần Windows 10/11 64-bit. Có card NVIDIA thì Chế độ Thật chạy nhanh hơn; không có card vẫn chạy được bằng CPU.
